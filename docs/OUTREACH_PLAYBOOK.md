## 📊 Campaign Tracking Sheet Setup

Create a simple Notion table or Google Sheet with these columns:
1. **Company Name**
2. **Contact Name & Role** (e.g. Founder, VP Product)
3. **Channel** (Email / LinkedIn / Twitter DM)
4. **Date Sent**
5. **Video Clicked?** (Loom notifications tell you when they watch!)
6. **Follow-Up Date** (+3 days)
7. **Status** (Sent / Replied / Screening Scheduled / Rejected)
8. **Notes**
